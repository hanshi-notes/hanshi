The experimental integration uses the `Vendor/swift-markdown-engine` Git submodule. Local modifications add AppKit hosting, preview geometry and source mapping, host-controlled links, diagram images, and preview regression fixes. The optional HighlighterSwift and SwiftMath bridge products are not linked; Hanshi supplies its existing renderers.
