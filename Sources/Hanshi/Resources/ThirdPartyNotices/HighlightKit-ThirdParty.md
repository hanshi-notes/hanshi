# Third-party notices

HighlightKit is a Swift port of, and remains token-compatible with:

## highlight.js

BSD 3-Clause License, Copyright (c) 2006 Ivan Sagalaev and highlight.js
contributors — <https://highlightjs.org>

HighlightKit's parsing engine semantics, the 64 bundled language grammars
(`Sources/HighlightKit/Languages/`), the relevance-based automatic language
detection model, and the fidelity-test corpus derive from highlight.js.
The fixtures under `Tests/HighlightKitTests/Fixtures/` are generated by
running the actual highlight.js source with a token-capturing emitter, and
every release asserts token-exact output against them.

The GitHub light/dark themes are ports of highlight.js's `github.css` and
`github-dark.css` (which in turn follow GitHub's Primer color system).
